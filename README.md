# Pocam

Pocket Camera — offline-first Android camera application.

## Stack
Kotlin, Jetpack Compose, Material 3, CameraX and Camera2.

## Design
Immersive edge-to-edge preview in portrait and landscape; circular icon-only controls; white shutter; long-press shutter to open a radial mode selector, drag to choose, release to select and close. Optional CPU/RAM overlay. System dynamic colors and approved pocket-camera branding.
